### Problem

 How do I add images to a PDF file on a Mac? ### Solution 1 - For multiple images into a single PDF

1. Select all images in Finder by holding down the Command key and selecting
2. Ctrl-click on of the files and select Open With Preview[![](/wp-content/uploads/2017/04/macOS_Finder_select_multiple_files.png)](/wp-content/uploads/2017/04/macOS_Finder_select_multiple_files.png)
3. In Preview, select File, Print. In the lower left, select PDF, Save as PDF and give it a name.
4. Open the PDF in Preview and check it. You may have to rotate pictures using Command-R or Command-L and save it again.[![](/wp-content/uploads/2017/04/macOS-Preview-Print-PDF-Save-as-PDF.png)](/wp-content/uploads/2017/04/macOS-Preview-Print-PDF-Save-as-PDF.png)
 



### Solution 2 - For a single image to an existing PDF

1. Open the image you want to insert with Preview (from Finder hit spacebar then Open in Preview)[![](/wp-content/uploads/2017/04/macOS_File_Export_as_PDF.png)](/wp-content/uploads/2017/04/macOS_File_Export_as_PDF.png)
2. Select File, Export to PDF [![](/wp-content/uploads/2017/04/macOS_Edit_Insert_Page_from_file.png)](/wp-content/uploads/2017/04/macOS_Edit_Insert_Page_from_file.png)
3. Open the PDF you want to add to in Preview
4. Select Edit, Insert, Page from File and select the file created in step 2
5. File, Save
 
 There is paid software that has more control than the built-in Preview app. Any photo program on the Mac can also be used to Print to PDF using solution 1.
