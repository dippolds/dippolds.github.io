<span>Requirements</span> Nikon ViewNX (free) SmugMug Mac Uploader and account MAC - Change ImageCapture not to open iPhoto automatically Nikon N80 - File Sequence Numbers ON, RAW only <span>Functions</span> Copy from Camera () Adjust RAW photos and create JPG files Upload to SmugMug Backup Optional Enhancements in Photoshop Elements <span>Workflow</span> 1. Plug in Nikon D80 to Mac. 2. Create a folder on the desktop with preferred name (example <span>200712 Bermuda</span>). Create subfolders called <span>RAW</span> and <span>JPG</span>. 3. Copy the files from the attached camera to the new <span>RAW</span> folder 3b. If Geocoding, do now on the RAW files using [GPSPhotoLinker](http://oregonstate.edu/~earlyj/gpsphotolinker/index.php) 4. Open ViewNX and navigate to the <span>RAW</span> folder created earlier 5. For each photo, delete, or adjust exposure and white balance 6. File, Convert Files, JPG, size unchanged, Destination folder = <span>JPG</span> folder 7. Launch SmugMug Mac Uploader 8. Selected Files. Drag files in JPG folder. Create a New Gallery with name from step 2. 9. Click Upload. Goto SmugMug.com to organize 10. Backup the folder created in step 2 Optional Workflow [Photoshop Elements steps](http://digital-photography-school.com/blog/a-5-step-photoshop-elements-workflow/) use NEF (raw) file as a start, save DNG to RAW folder Crop / Rotate Adjust Levels Adjust Colors Remove Marks with Clone Sharpen
